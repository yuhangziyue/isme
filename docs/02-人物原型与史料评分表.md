## 二、逐人评分证据

### 1. 曹操（155–220）｜65 / 55 / 88 / 28 / 85 / 25

- **D1=65**：三下"求才令"（建安十五年、十九年、二十二年）公开"唯才是举"，把"盗嫂受金"者与廉士并列，颠覆两汉以德取人惯例（《三国志·武帝纪》注引《魏书》）；但终身不称帝、治政多用汉家旧框架，变革止于用仕与军事，故不给满分。
- **D2=55**：注《孙子》并强调"法度"，军法严整（坐骑惊入麦田，割发代首，《武帝纪》注引《曹瞒传》）；但用兵好用奇、生活通脱，《曹瞒传》载其"轻易""佻易无威重"，严整与随性并存，居中。
- **D3=88**：年轻时自许"治世之能臣，乱世之奸雄"（《世说新语》识鉴注引《魏书》/孙盛《异同杂语》）；横槊赋诗、宴饮笑傲；权力舞台绝对中心。
- **D4=28**：杀边让、孔融、荀彧（忧死）、杨修，屠徐州（《武帝纪》《后汉书·陶谦传》）；对降主如关羽又极厚待，恩是手段不是本能——低在"无差别心慈"，非无恩。
- **D5=85**：官渡之战以少抗多、奇袭乌巢，亲率五千烧粮，豪赌型决策巅峰；赤壁败走仍三笑（《山阳公载记》），崩盘情绪恢复极快。
- **D6=25**：《让县自明本志令》"设使国家无有孤，不知当几人称帝，几人称王"，以事实成效自辩；治名法、行屯田，先吃饱再谈名教。但年轻时有"欲为一郡守，好作政教"的功名理想，且终身守汉臣底线，故非极低。

### 2. 诸葛亮（181–234）｜58 / 95 / 40 / 68 / 30 / 95

- **D1=58**：制《蜀科》、设堰官、作木牛流马、八阵图，制度与技术上均有创设；但旗号是"兴复汉室，还于旧都"（《前出师表》），变革是手段，守的是旧统，故居中偏上。
- **D2=95**："政事无巨细，咸决于亮"（《三国志·诸葛亮传》）；"罚二十以上皆亲览"（《襄阳记》载杨颙谏语）；账册军备亲自核校，典型的系统与清单人格。
- **D3=40**："苟全性命于乱世，不求闻达于诸侯"（《出师表》自陈）；刘备三顾乃出；执政后不植党、不骄下，锋芒全在事功不在姿态。
- **D4=68**：治蜀"科教严明，赏罚必信，无恶不惩，无善不显"（《诸葛亮传》陈寿评），法严；同时"庶事精练，物理其本，循名责实"，民"畏而爱之"；对廖立、李严废而不杀、且许其复用，严中有恩。
- **D5=30**：否决魏延子午谷奇谋（《魏延传》："亮以为县危，不如安从坦道"）；"诸葛一生唯谨慎"；五次北伐必求粮道万全，不弄险——风险预算极度保守。
- **D6=95**："鞠躬尽力，死而后已"（《后出师表》，并见《前出师表》情志）；知不可为而为之，以兴复为信仰；身后"内无余帛，外无赢财"（《诸葛亮传》）。

### 3. 张良（？–前186 左右）｜60 / 82 / 25 / 62 / 80 / 55

- **D1=60**：建议刘邦弃洛阳都关中、封韩信齐王以稳军心、鸿门宴前后连环布局，每一步都在重写规则；但方法上尊黄老、因势而不造势，非制度型变革者。
- **D2=82**："运筹策帷帐之中，决胜于千里之外"（刘邦语，《高祖本纪》《留侯世家》）；谋的本质是事前推演多套剧本，鸿门、烧绝栈道、蹑足封王皆预演产物。
- **D3=25**：辞三万户封、自选留侯；"愿弃人间事，欲从赤松子游"（《留侯世家》）；功成即从权力中心后撤，存在感最低的开国元勋。
- **D4=62**：为韩报仇是义（弟死不葬，悉以家财求客刺秦）；劝刘邦"忠言逆耳利于行"；但劝都关中、劝封雍齿以安功臣，用的是冷静的利益计算，恩出于智。
- **D5=80**：博浪沙铁椎刺秦（120 斤椎误中副车）是全盘皆输也敢做的豪赌；天下大定后又极清醒地"愿封留足矣"，敢赌的另一面是敢在最高点离场。
- **D6=55**：前期为韩复仇、为汉定天下，有明确政治理想；晚年"道引轻身"，理想让位于自全之道——理想主义者主动转向，居中。

### 4. 韩信（约前231–前196）｜80 / 38 / 80 / 40 / 55 / 40

- **D1=80**：背水列阵破赵，自陈"置之死地而后生"（《淮阴侯列传》），刻意反兵法教条；潍水壅囊破齐楚、十面埋伏，战术上是持续创新者。
- **D2=38**：早年不治生业、从人寄食、受胯下之辱而不立产业规划；为帅则军法神出鬼没，但个人生涯始终缺乏长线安排，钟离眜事、与陈豨之谋皆首尾狼狈。
- **D3=80**：登坛拜将即论天下大势（"汉中对"），当面与刘邦论"多多益善"（《淮阴侯列传》）；矜功自伐，自信写在脸上。
- **D4=40**：报漂母一饭千金、召辱己少年为中尉，有恩仇分明的宽厚面；但郦食其已说齐而下，仍趁夜袭齐，致郦生被烹，成事优先于同袍。
- **D5=55**：战术上敢以万余新兵背水抗赵二十万，胆略顶级；但政治上三次关键犹豫——拒蒯通三分天下之议、不肯反、又怨望，"狡兔死，良狗烹"临头才下决心。战场豪赌、人生慎断，撕裂型分数。
- **D6=40**：要的是"封王""功多"，自认功当如此；对刘邦有"汉王遇我甚厚"的知遇底线，无更高政治信念；被诛核心悲剧是事功逻辑遇到帝王逻辑。

### 5. 苏轼（1037–1101）｜88 / 35 / 78 / 85 / 82 / 60

- **D1=88**：写诗"以文为诗"、填词开豪放一派（《念奴娇·赤壁怀古》）、画尚文人写意、谈禅说厨；在任何领域都拒绝被既有格套收编。
- **D2=35**："行于所当行，止于不可不止"（《文说》自评文章，亦是其人）；理财非所长，乌台诗案前政治上全无避祸安排；兴修杭州西湖、徐州抗洪时却又能系统组织——对事能规划，对己随兴。
- **D3=78**：科场名动京师，一生交游满天下，"上可陪玉皇大帝，下可陪卑田院乞儿"（宋人笔记载其自语）；外放不失声量，天然人群中心。
- **D4=85**：黄州救溺婴、杭州办安乐坊（中国较早公立病坊之一）、惠州捐犀带修桥；与弟苏辙夜雨对床、对仆役亦温，宽厚是人格底盘。
- **D5=82**：乌台诗案下狱当死，出狱即"塞上纵归他日马"；贬惠州"日啖荔枝三百颗"，再贬儋州（宋时死地）仍"我本儋耳人"；绝境中的情绪稳定性近乎天赋。
- **D6=60**：地方政务极重民生实效（苏堤、疫苗、赈济），非纯理想主义；但政治上始终不肯附和新党或旧党任何一边，"一肚皮不合时宜"（朝云语），道义感压过利益计算，居中偏上。

### 6. 王安石（1021–1086）｜92 / 80 / 55 / 25 / 60 / 96

- **D1=92**：熙宁变法颁均输、青苗、募役、市易、保甲、方田均税十余项，整体重构国家财政与社会组织，是帝制史上最系统的顶层重设之一；"天变不足畏，祖宗不足法，人言不足恤"（《宋史·王安石传》载为反对派概括，安石不辩）。
- **D2=80**：鄞县知县任内先试青苗雏形，是地方试点再全国推广的路径；制置三司条例司作为专门立法机构推进；政策设计精密，败在执行与用人，不赢在无序。
- **D3=55**：廷对神宗侃侃而谈，"人言不足恤"需要极强的当众坚持；但生活上极度俭朴、不事应酬、面垢不洗（《邵氏闻见录》等笔记多载，虽带立场，其不近人群则一），影响力靠文本与相位，不靠人际魅力。
- **D4=25**：视反对者为"流俗"，与司马光、苏轼、欧阳修等师友全面决裂而不回头；推行中拒绝对受损阶层做任何柔性过渡（青苗强制抑配），逻辑的刚性压过对人的体恤。
- **D5=60**：以翰林学士骤拜参知政事、赌上全部政治生命强推，敢押；但每一步都走制度通道（设司、颁令、用人），不是冒险型赌徒，是信念型孤注一掷，故不过高。
- **D6=96**："致君尧舜"是公开自任（《上仁宗皇帝言事书》即已陈明）；变法目的是"民不加赋而国用饶"的先王之道——他自认为是最纯粹的儒家，失败是因为对手与时代配不上他的理想。

### 7. 王阳明（王守仁，1472–1529）｜85 / 72 / 66 / 80 / 88 / 72

- **D1=85**：龙场悟道，提出"心即理""知行合一""致良知"，把程朱向外格物的路径整个倒转，是儒学内部的范式革命；兵事上亦不守常规（编练民兵、信牌诱敌）。
- **D2=72**：平南赣、平宁王、平广西，每次先办团练、行十家牌法、严保甲、定赏罚格，组织设计严密；讲学亦有教条（《训蒙大意》《教约》），心学的自由立在极严的功夫次第上。
- **D3=66**：不恋京官、长期求退；但临事必当仁不让——宁王反，无一诏一兵而毅然起义，用各道印信调集军队，敢在聚光灯下担灭族风险，该出场时绝不后退。
- **D4=80**：平贼"可抚则抚"，卢珂、黄金巢等受抚；对弟子、百姓、甚至政敌（对刘瑾只避不骂）皆留余地；临终"此心光明，亦复何言"，宽厚来自哲学不是策略。
- **D5=88**：宁王叛乱时他手上无兵，先用假情报、反间计拖住朱宸濠十几天，再仓促聚兵，鄱阳湖决战火焚连环舟，43 天平定蓄谋十年的叛乱——以无备对有备，镇定与豪赌都是顶级。
- **D6=72**：以"良知"为最高准则，敢在程朱官方意识形态外另立宗旨，理想强度极高；但他不同于王安石处，是"事上磨炼"、强调在具体事功中致良知，不悬空谈道，故事功与理想平衡，居中偏上。

### 8. 曾国藩（1811–1872）｜35 / 96 / 45 / 55 / 40 / 85

- **D1=35**：以"卫道"起兵讨太平天国（《讨粤匪檄》），学术主宋儒、治军承戚继光成法，"结硬寨、打呆仗"，明确不做讨巧的创新；洋务初开（安庆内军械所、幼童留美）是被现实推着走，非主动求变。
- **D2=96**：三十年日课不断（早起、静坐、读书、写日记自省），家书系统化教育子弟；行军每到一处先勘察地形、扎硬墙、挖深沟，"多算"到极致。
- **D3=45**：自认"钝拙"，不善张扬；但两次出山、以在籍侍郎身份拉起湘军，当争的兵权、厘金、督抚之权一步不让，是内敛而不消极的进取心。
- **D4=55**：治军"爱护士卒"与"严刑峻法"并存，在江西办团练以酷杀得"曾剃头"绰号；保举极慷慨、对同僚极谦卑（家书屡教），但对叛者与溃败者零容忍，恩威并施且偏威。
- **D5=40**：靖港、湖口大败两次投水自尽（被救起），善打呆仗、不善奇险；"屡败屡战"（奏折语，传为幕僚改"屡战屡败"），靠不输光的谨慎和熬劲而非豪赌取胜。
- **D6=85**：以理学信仰治军，起兵檄文捍卫名教；天津教案中明知声名尽毁仍按"务实守约"了结，临终前对"外惭清议、内疚神明"的痛苦，恰说明道义感是其内核——只是成年后学会向现实低头。

### 9. 吕雉（吕后，前241–前180）｜45 / 62 / 70 / 18 / 82 / 28

- **D1=45**：称制期间大体沿用萧何、曹参的休养生息框架，"政不出房户，天下晏然；刑罚罕用，罪人是希；民务稼穑，衣食滋殖"（《史记·吕太后本纪》太史公曰）——以稳定为最高价值，无大创设。
- **D2=62**：诛彭越、诱韩信的行动步骤密不透风（与萧何合谋、预先布局舍人告变）；但家族权力安排上把诸吕封王凌驾于政治契约（白马之盟）之上，系统设计留了致命缺口。
- **D3=70**：刘邦起兵前她即以强势主内、随军中；为人质于楚营两年不屈；称制后公开坐朝问政，是帝制中国第一个实际行使皇权的女人。
- **D4=18**：诛韩信、醢彭越、人彘戚夫人、鸩杀赵王如意（《吕太后本纪》），对权力威胁者的残酷为史所仅见；唯一显著的柔性给了张良、审食其等"自己人"和整体民生。
- **D5=82**：刘邦死后四天秘不发丧，与审食其谋尽诛诸将（《高祖本纪》），敢在权力真空期掀全盘；最终被郦商劝下——敢于把最大风险放上桌面的人。
- **D6=28**：政治目标清晰：保刘姓江山（她的理解里含吕家）、保安民；白马之盟可破、人伦可越，规则为权力与秩序服务。但她终未改刘姓国祚、废子自立，底线感尚存，故不至最低。

### 10. 武则天（624–705）｜88 / 58 / 95 / 22 / 88 / 30

- **D1=88**：改国号为周、迁都洛阳、改官制文字（造新字）；首创殿试亲策贡士（载初元年）、开武举（长安二年）、许官民自荐（试官制度），把人才通道整个重铸；打击关陇集团、重订《姓氏录》，社会结构层面动刀。
- **D2=58**：设铜匦、开告密、用酷吏（来俊臣、索元礼、周兴）是制度化的肃反机器，说明她懂系统；但酷吏政治随用随抛、财政与边疆缺乏长期稳定章法，系统服务于权斗而非治理，故居中。
- **D3=95**：从感业寺回宫、废王立武、二圣临朝、垂帘、称帝，每一步都是向整个礼法秩序正面夺舞台；"明朝游上苑，火急报春知"式的公开宣示，支配欲毫无遮掩。
- **D4=22**：废杀李忠、李弘（死因有争议，《新唐书》持毒杀说，《旧唐书》措辞含糊，取存疑）、李贤，重用酷吏株连重臣；对政敌冷硬至极。同时对狄仁杰、姚崇、宋璟等真才又极度信任包容——恩是精准投放。
- **D5=88**：以昭仪之身赌皇后位、以太后之身赌皇位，全是胜率不明、输即灭族的局；徐敬业扬州起兵、宗室诸王起兵时均快速铁腕平定，压力下决策极快。
- **D6=30**：崇佛（《大云经》）、尊号、造字都是为政权合法性服务的工具；用人看效、杀人看需，典型事功逻辑。但去帝号、归乾陵、立无字碑（碑为事实，"无字"意图为后世解读），晚年以"则天大圣皇后"收场，说明她清楚秩序与名分的终极重量，故非最低。

### 11. 长孙皇后（601–636）｜42 / 80 / 22 / 90 / 68 / 85

- **D1=42**：守贞观初年的克制基调，主动压制外戚（力劝太宗勿任长孙无忌为相，《旧唐书·后妃传》《贞观政要》），不做制度上的出头鸟；以《女则》（已佚，内容据本传）整理传统规范，守成型。
- **D2=80**：太宗盛怒时不当面硬顶，等其气消再缓谏（对养马宫人致死事件的劝谏，《贞观政要》）；对自己的身后事明确要求薄葬、因山而葬（《旧唐书》载其遗言），一生连进谏都有节奏设计。
- **D3=22**：明确拒绝议政，"牝鸡之晨，惟家之索"引以自戒（《旧唐书》）；玄武门之变时亲临勉慰将士是唯一一次走到前台，事后立刻退回，存在感高度自律。
- **D4=90**：为魏征直言请赏（"妾闻主明臣直，今魏征直，由陛下之明"，《贞观政要》）；保护被迁怒的宫人；对诸子"俭以息人"；东宫服用有缺亦不偏私长子，宽厚有原则。
- **D5=68**：玄武门当天亲到军前授甲勉慰，在灭门级风险现场保持镇定；但平日风格是防患于未然（劝兄逊权、劝帝纳谏），靠提前布局消化风险，不到需要豪赌的境地。
- **D6=85**：遗言仍在劝"亲君子，远小人，纳忠谏，屏谗慭，省作役，止游畋"（《旧唐书》《资治通鉴》），以儒家政治理想为终身立场；她的温柔是信念，不是性格软弱。

### 12. 冯太后（文成文明皇后，441–490）｜90 / 75 / 78 / 45 / 80 / 52

- **D1=90**：太和改制的真正启动者（孝文帝亲政前多数新法已由其临朝期间颁布）：班禄制（给官员发俸禄以治贪）、三长制（重建基层编户）、均田制（国家按口授田，影响隋唐均田与租庸调），是中古制度革命级的三连环，《魏书·皇后传》《食货志》可按。
- **D2=75**：改革按"班俸禄（484）→ 均田令（485）→ 三长制（486）"的次序推进，先给官员退路再动吏治、先授田再编户，节奏与配套设计清晰；用李冲等能臣操盘，制度化能力极强。
- **D3=78**：两度临朝（诛乙浑首次掌权、献文帝暴崩后再朝），权力意志公开而强硬；与孝文帝"二圣"并立，是主动站到台前的执政者。
- **D4=45**：诛权臣乙浑果断、献文帝之死史多暗示与她有关（《魏书》措辞"暴崩"，史学界存疑，不取实锤）；对政敌冷硬。但改革本身以均田惠民、立乡学、宽工商为内容，对普通民力是休养的——对敌人狠，对民厚。
- **D5=80**：献文帝禅位后仍想收权，她以退为进、再度发动政变式布局重掌大权；推行均田要面对鲜卑勋贵和宗主督护制的全面抵抗，押上摄政权威硬推，赌性与节奏兼备。
- **D6=52**：汉化改革有明确的文明理想（她本人是汉化最深的鲜卑统治者之一，亲作《劝戒歌》《皇诰》）；但手段高度务实：先班禄赎买官僚、再以均田绑定国家与农民，理想与交易并行，略居中。

### 13. 李清照（1084–约1155）｜90 / 30 / 75 / 55 / 62 / 50

- **D1=90**：《词论》提出"词别是一家"，当面批评柳永"词语尘下"、苏轼词"皆句读不葺之诗"，以晚辈女性身份重订词坛标准；词作本身从婉约到豪放（《夏日绝句》"生当作人杰"）突破性别与文体双重成规。
- **D2=30**：晚年颠沛中亲自押运十五车金石文物南下（《金石录后序》），说明对挚爱之事能极有组织；但日常与理财上"食无肉"式随性，再嫁张汝舟这场婚姻几乎无任何风险尽调，人生管理严重偏科。
- **D3=75**：她是文坛沙龙的绝对中心，少女时即以词得名、与丈夫赌书泼茶（《金石录后序》自记），才情与观点都高度外露；《词论》敢以女性晚辈身份逐家点评本朝名公。
- **D4=55**：对赵明诚情真、对文物护惜如命、诗中怀人宽厚；但对不堪之人毫不留情——发现张汝舟骗婚夺物，宁肯依宋律"告夫者徒二年"也要起诉离婚，坐牢九日（经綦崈礼等营救），对恶人不施恕道。
- **D5=62**：南渡乱局中护文物、告官、坐牢、再嫁再离，每一步都是世俗眼光里的灭顶风险，她全做了；但她是被命运推到赌桌前，不主动追险，情绪也确有"寻寻觅觅，冷冷清清"的至暗时刻，故居中偏上。
- **D6=50**：前半生"甘心老是乡矣"于金石雅趣，非道学家；晚年诗讽苟安朝廷（"至今思项羽，不肯过江东"），气节凛然——她的道义不在礼教，在文化认同与做人的真，居中。

### 14. 秦良玉（1574–1648）｜48 / 88 / 58 / 58 / 75 / 90

- **D1=48**：所练"白杆兵"有独特的山地长枪装备与战法，是军事技术上的创新；但政治上忠于明室到底、拒绝张献忠招降、以石柱土司身份恪守臣节，价值与制度层面是坚定的守成者。
- **D2=88**：白杆兵号令森严、行伍整肃（《明史·秦良玉传》载其驭下"戎伍肃然"）；万里勤王、自备军粮，行军调度有据；丈夫马千乘被冤死后仍按法袭职、不反不乱，一生行动有台账。
- **D3=58**：不爱声张，史载其"仪度娴雅"（《明史》），但三次奉命勤王、敢亲赴京城面见崇祯、直接上奏弹劾排挤她的总兵（邵捷春、杨嗣昌事），该争的体面与战功当面争。
- **D4=58**：所部秋毫无犯、以军纪护民；对朝廷和宗族有强烈责任感，兄弟秦邦屏、秦民屏先后战死，她带族中女子续战。但军法严酷、对逃溃不留情，宽厚有度。
- **D5=75**：浑河之战白杆兵以数千川军硬抗努尔哈赤后金军、大部战死仍不退；崇祯三年千里入卫京师；以土司孤兵守到明朝灭亡——知道大概率是死局仍出兵，镇定与胆略一流。
- **D6=90**：崇祯召见赐诗"世间不少奇男子，谁肯沙场万里行"；临终诫孙"吾以一孱妇蒙国恩二十年……其唯勿负国"（《明史》），忠节是她全部选择的根，故高。

### 15. 孝庄文皇后（1613–1688）｜50 / 78 / 30 / 78 / 85 / 65

- **D1=50**：辅佐顺治、康熙两代幼主，在满蒙联姻、议政王大臣会议与汉官之间走平衡，政策上有调整（如支持康熙擒鳌拜后的秩序重建、赞助平三藩的内帑），但从不以自己名义改祖制，是"借制度做事"的人。
- **D2=78**：皇太极死后帝位空悬，她运作福林继位、制衡多尔衮；顺治早逝后果断选立出过天花的玄烨、立四大臣辅政的制衡局；康熙朝重大节点（擒鳌拜、平三藩）背后是她长期的布局与节奏控制。
- **D3=30**：终身未垂帘，明确拒绝朝臣上尊号、拒绝走到前台；"太后下嫁多尔衮"为清初三大疑案之一，现有档案证据不足以证实，测评不采用——她的风格本就是让所有事发生在自己名字之外。
- **D4=78**：待下宽和、生活节俭（三藩之乱时发后宫金帛犒军），对康熙的教育倾注全部心血（《清史稿》载其抚育训诲）；但对多尔衮集团、对跋扈的鳌拜，她能等、能忍、也能在时机到时一击解决——柔是方法。
- **D5=85**：幼子登基、摄政王咄咄逼人、随时可能母子被废的七年，她以婚姻传闻和政治妥协稳住全局；多尔衮猝死/病死后迅速推动亲政——一生都在信息不全的生死局里做冷静押注，且从不亲自下场失态。
- **D6=65**：信佛、节俭、以护佑大清基业为信念，有强烈的责任伦理；但具体决策完全务实——联姻、妥协、等待、交换，她的理想从不以口号出现，居中偏上。

### 16. 冼夫人（冼英，约522–602）｜62 / 72 / 50 / 88 / 78 / 80

- **D1=62**：力排岭南俚族各部"自成一统"的惯性，推动俚汉融合、"诫约本宗，使从民礼"（《隋书·列女传·谯国夫人》）；率众归陈、再归隋，每一次归附都是对部落旧政治形态的主动革新；但方法上依托中原制度，不另起炉灶。
- **D2=72**：与丈夫冯宝（高凉太守，汉人流官）配合，以首领权威保证政令在俚区执行；平侯景之乱相关战役、平李迁仕、平欧阳纥、平王仲宣，历次行动都先联络、再出兵、后请封，章法清楚；将梁、陈、隋三朝赐物各藏一库，朝廷赏赐即政治档案。
- **D3=50**：岭南数郡奉为"圣母"，威望天然是人群中心；但她始终通过丈夫、子孙、朝廷使节行动，晚年才以谯国夫人身份开幕府、置长史，舞台欲有节制。
- **D4=88**："我事三代主，唯用一好心"（《隋书》《北史》载其对孙语）——以信义待人；平乱后"岭表悉定"、安抚各部而非清算；对叛乱的亲族（如孙子冯暄违令）先下狱治罪再启用，恩与公分明。
- **D5=78**：侯景之乱时岭南局势混沌，她判断形势后亲率千余人诈送礼、突袭李迁仕；陈亡后岭南无主、各部请其自立为"岭南圣母"以保境，她在隋军压境时选择归附而非割据——在最容易自立的时刻放弃自立，是另一种高风险决策。
- **D6=80**：毕生选择的最高准则是"唯用一好心"和避免岭南战火，对梁、陈、隋三朝的忠诚实质是对秩序与民生的忠诚；但她极懂以册封、朝贡、质子、婚姻换取现实空间，理想与务实高度融合，取 80。
