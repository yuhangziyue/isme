# 「我是谁转世」中国历史名人人格原型测评 · 设计文档 v1.0

> 设计：苏姐（产品总监视角）｜日期：2026-09-16
> 定位：一套**有理论依据、人物正史可考、男女均衡、可直接施测**的人格原型测评。
> 形态：48 题情景行为问卷（5 点计分）→ 六维量表 → 与 16 位历史人物原型做距离匹配 → 输出主原型 + 次原型 + 维度数据 + 人物解析。

---

## 0. 一句话产品定义

> **不做"你是哪个皇帝"的娱乐抽签，做"你的行为倾向与哪位被正史记录的真实决策者同构"的自省工具。**

差异化：娱乐测试给标签（巴纳姆效应，套谁身上都对）；本测评给**维度数据 + 史料证据 + 盲区警告**，让用户拿到可证伪的结果。

## 1. 权威依据（为什么这套东西"测得出东西"）

### 1.1 维度骨架：大五人格模型（Five-Factor Model / OCEAN）

- 学术来源：McCrae & Costa 的五因素模型，人格心理学界复现性最高、跨文化验证最充分的特质模型（Digman, 1990；McCrae & Costa, 1997）。
- 中文常模修订：王登峰等对中国人人格结构（QZPS）的研究表明，大五框架在中国文化下基本成立，但"人际关系"与"处世方式"的权重更高——这是本测评在标准五维外增加第六维的原因。

六个维度与大五的对应：

| 本测评维度 | 大五对应 | 本土化调整 |
|---|---|---|
| D1 变革鼎新 ↔ 守常稳健 | O 开放性 | 增加"祖宗之法可不可变"的中国决策语境 |
| D2 严谨规划 ↔ 灵动随性 | C 尽责性 | 对应"日课/磨勘"传统与文人随性两种典型 |
| D3 外放进取 ↔ 内敛沉静 | E 外向性（含支配性） | 加入"争与不争"的权力动机表达 |
| D4 怀柔宽厚 ↔ 冷峻刚硬 | A 宜人性反向面 | 对应"王道—霸道""恩—威"这对中国管理母题 |
| D5 镇定敢赌 ↔ 慎惧多虑 | N 神经质（反向）+ 风险倾向 | 单独拉出"赌性"，历史人物分野最大的一维 |
| D6 道义理想 ↔ 事功务实 | 价值观维度（大五之外补充） | 对应儒/法、义利之辨、动机理论（McClelland） |

### 1.2 第六维的理论支撑

- McClelland 动机理论：成就动机、权力动机、亲和动机之外，人的**价值定向**（原则导向 vs. 结果导向）是独立预测变量。
- 中国思想谱系：儒家"义以为上"（《论语·阳货》）vs. 法家"循名实而定是非，因参验而审言辞"（《韩非子》）vs. 道家因循。这一维度直接决定一个人在"手段是否正当"上的选择，是历史人物最核心的分野之一（王安石 vs. 张居正式的差别不在能力，在哲学）。

### 1.3 人物原型法（Prototype Matching）

- 方法学参照：Westen & Shedler 等人的 SWAP（Q-sort 原型匹配）思路——不是把人硬塞进类别，而是计算受测者特质剖面与"典型原型剖面"的距离，输出最接近的原型及距离。
- 本测评每位历史人物 = 一个六维原型向量，分数**不由后人喜好拍脑袋**，而由编码规则产生（见 §4 与《02-人物原型与史料评分表》）。

### 1.4 防巴纳姆设计（娱乐测试的通病，本测评的红线）

1. 结果必须给**六维具体分数**而非一段万能赞美；
2. 每个人物解析必带**盲区/阴影面**（与优点同出一源的代价）；
3. 主原型之外给 Top3 距离，明确告知"你是在多个相近原型之间"，降低宿命感；
4. 人物画像基于**可考事迹**，每条关键判断标注史料出处（《史记》《三国志》《明史》等）。

## 2. 六维模型详细定义

每维 0–100 分，两端均为**中性命名**（没有"好的一端"），避免默认褒贬：

### D1 变革鼎新（高）— 守常稳健（低）
- 高分：质疑惯例、敢改祖制、拥抱未经检验的新方法，愿意承担"变错了"的骂名。
- 低分：尊重时间筛选过的秩序，先立后破，宁可慢，不轻易拿存量冒险。
- 典型问题意象："祖宗之法，到底可变不可变？"

### D2 严谨规划（高）— 灵动随性（低）
- 高分：节点、清单、账目、日课；承诺必达；靠系统而非临场发挥。
- 低分：边做边调、多线程、在混乱和即兴中反而出灵感；厌烦被计划绑死。
- 风险：高→僵化；低→不可预期。

### D3 外放进取（高）— 内敛沉静（低）
- 高分：享受注视、主动争资源、当面碰撞、天生的议程设定者。
- 低分：幕后推演、实力说话、"不争而善胜"；该出手时不含糊，但不恋舞台。
- 注意：低 D3 ≠ 没野心，只是野心不通过"存在感"表达（如司马懿、孝庄）。

### D4 怀柔宽厚（高）— 冷峻刚硬（低）
- 高分：先给台阶、读情绪、服人之心、愿为关系按下自己的委屈。
- 低分：规矩面前没有特殊、用人以能不以顺、关键时刻支付"心狠"的代价。
- 注意：低 D4 的历史人物同时常有强执行力——这是测量上最容易被误读为"坏人"的一维，报告必须中性叙事。

### D5 镇定敢赌（高）— 慎惧多虑（低）
- 高分：崩盘时更冷静、胜算不足也敢押重注、决策快、少内耗。
- 低分：设想一切失败可能、先留退路、"不犯大错"本身是竞争力。
- 注意：低分不是胆小——诸葛亮低 D5（子午谷之议），这是风险预算风格，不是勇气排名。

### D6 道义理想（高）— 事功务实（低）
- 高分：道义站不住则利再大不为；为信念牺牲安逸、功名、安全。
- 低分：结果是硬通货，手段可以调整，"让人真正吃上饭"胜过道德文章。
- 注意：低分不是无底线（曹操亦有《让县自明本志令》的自陈），而是判断顺序里"成效"排在"名正言顺"之前。

2. **事迹可考**：至少 3 件时间、对象、后果清楚的关键决策，可支撑维度编码；
3. **形象立体**：同时有"成事方式"和"代价/争议"，拒绝扁平圣人或扁平反派；

- **性别均衡**：8 男 8 女；女性人物全部是**独立决策者**（有自己名下的政治/军事/文化决策），不是"某位男性的附属贤内助"叙事——长孙皇后与孝庄的入选依据也是她们独立做出的进谏、平衡、抚育与托孤决策。
- **匹配不限性别**：受测者的性别不参与计分，男性可匹配武则天，女性可匹配曹操。历史上这两人原型本就高度相近，这是结论不是 bug。
- 落选说明：司马懿（与诸葛亮/曹操原型重叠且维度区分度不足）、张居正（与曾国藩/王安石重叠）、慈禧（正史与近代史材料立场争议过大，v1 回避）、班昭/上官婉儿（独立决策事件数量不满足标准 2，进 v2 候选池）。

## 4. 人物原型评分规则（不是拍脑袋）

1. **三事迹编码法**：每个维度为每位人物找至少 2–3 条可考事迹，独立给分（0/25/50/75/100 五档锚点），再取均值，证据见《02-人物原型与史料评分表》。
2. **同时代史料优先**：本人著述/奏疏/诏令 > 当朝正史本传 > 后世正史 > 后世史评。史评（如《读通鉴论》）只用于解释，不直接给分。
3. **争议显性化**：同一事迹有相反解读时（如韩信在政治关键时刻的犹豫、孝庄下嫁之谜），取多数学界共识并在解析中注明，不消费宫闱秘闻。
4. **反向校验**：全部 16×6 个分数完成后做原型间距离矩阵检验，任何两位总分向量距离过近（欧氏距离 <20）必须重新核档或换人；实际最小距离为 22.8（张良—孝庄），通过阈值（见 §6）。

## 5. 题库设计（48 题，≤50 硬约束）

### 5.1 结构

- 6 维 × 8 题 = 48 题；每维 4 道正向计分 + 4 道反向计分，平衡默认作答偏差（acquiescence bias）。
- 题型：**情景行为题**（"遇到 X，我会 Y"），不用自陈特质词（"我是个勇敢的人"——人会撒谎，行为句式更难美化）。
- 计分：5 点 Likert（1 非常不同意 → 5 非常同意）。
- 施测时长：10–12 分钟。

### 5.2 出题原则

1. **场景现代**：全部翻译成职场/生活/团队场景，不出古文题（古文题测的是文化水平不是人格）；
2. **社会赞许性控制**：高道义、高宽厚等"好看选项"用代价句中和（如"哪怕被说野心写在脸上""我认为那是必须支付的代价"）；
3. **维度隐藏**：题目乱序排列，不出现"以下属于计划性的是"之类的自曝；
4. **不设对错**：选项无分值外露，报告页才给维度解释；
5. 反向题在数据层用 key 字段处理，前端文案保持自然。

### 5.3 计分公式

- 单题贡献：正向题 `(v-1)/4×100`；反向题 `(5-v)/4×100`；
- 维度分 = 该维 8 题均值（0–100）；
- 原型匹配：对 16 位人物计算六维**欧氏距离平方**，最小者为主原型；同时输出第 2、3 近原型与差值；
- 差值 <15 时报告语改为"你在 A 与 B 之间，更靠近 A"，拒绝伪精确。

### 5.4 信效度与后续迭代（产品迭代项，诚实标注）

- 信度：v1 为内容效度优先的专家构建版；上线后应回收样本，目标各维 Cronbach's α ≥ 0.70；
- 效度：以大五量表（如 NEO-FFI 中译版）做同测效度，D1–D5 与对应大五维度相关应显著；
- 常模：回收 ≥500 份后建立分数常模，维度报告从"绝对分"升级为"百分位"；
- v1 定位：**自我省察与讨论工具，不是临床/招聘评估工具**——结果页必须明示。

## 6. 原型区分度验证（构建后自检）

用每个人物自己的原型向量生成"理想作答"（该维度高分题取对应倾向），跑匹配算法：

- 16/16 位人物的主匹配都是其本人（自洽性 100%）；
- 原型向量最小距离 22.8（张良—孝庄），全部 ≥20，区分度阈值通过；
- 最具话题性的一对：曹操 ↔ 武则天（25.6），符合史学常识（事功导向、高支配、敢赌、用人以能的改革型铁腕），双方解析互指镜像；
- 另做 ±1 档作答噪声的抗扰测试与 5000 份随机作答压测；
- 验证脚本与数据：`data/` 目录，`simulate.py` 可复现。

## 8. 产品视角的几个刻意取舍（苏姐批注）

1. **50 题上限是对的**。48 题、约 10 分钟是人格测试完成率的甜区；超过 15 分钟移动端流失率陡峭上升。要扩维度请走"核心 48 题 + 可选深度题包"，不要在首版加题。
2. **不给人物画像（遵照本版要求）**，视觉上线前，结果页的信息密度要靠雷达图和版式撑住；画像反而是巴纳姆效应的放大器，v1 不做是优点不是缺失。
3. **结果必须"有用"**。用户转发的动机不是"我是诸葛亮"，而是"这报告说我事必躬亲会耗死自己，确实"——所以盲区和行动建议是留存/传播核心，文案权重应高于赞美。
4. **商业化预留**：六维原始数据是高价值资产。团队版（团队角色互补分析）、情侣/搭档版（双向量匹配）都是现成的第二曲线，v1 数据结构已按可扩展设计（纯 JSON 驱动）。
