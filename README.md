# 我是谁转世 · 历史名人人格原型测评（v1.1）

48 个单选题、约 10 分钟 → 六维数据 → 在 16 位正史人物（男女各 8）中匹配你的人格原型。
Slogan：**「更好的了解自己，解锁天赋吧」**

## 使用

- 双击 `index.html`（或「打开测评.command」），离线可用，无需服务器。
- 手机浏览器打开即为移动版：一屏一题、点选自动跳下一题、布局按宽高自适应、无可见滚动条。
- 右上角「人物档案」：全屏翻阅 16 位人物，左滑/右滑切换，也可点两侧箭头或下方圆点；内容与测评结果页一致；左上「‹ 返回」回到原页面。

## 文件

```
index.html              # 单文件应用（数据已内嵌）
打开测评.command         # macOS 双击启动
simulate.py             # 原型自洽/区分度/抗噪/随机压测
data/questions.json     # 48 题（6 维 × 8，正反向各 4）
data/figures.json       # 16 位人物原型向量与解析
docs/                   # 设计文档、史料评分表、16 份人物解析
```

## 六维（大五 OCEAN 本土化 + 价值定向）

D1 变革鼎新↔守常稳健（O）｜D2 严谨规划↔灵动随性（C）｜D3 外放进取↔内敛沉静（E）
D4 怀柔宽厚↔冷峻刚硬（A）｜D5 镇定敢赌↔慎惧多虑（情绪稳定+风险倾向）｜D6 道义理想↔事功务实（价值定向）

## 边界

自我省察与讨论工具，不是临床诊断或招聘评估；性别不参与计分。

## 在线访问（GitHub Pages）

推送后在仓库 **Settings → Pages → Source 选择 `main` 分支 / 根目录**，稍等 1–2 分钟即可访问：

https://yuhangziyue.github.io/isme/

纯静态单文件，无后端、无构建依赖；`index.html` 已内嵌全部题库与人物数据，直接双击或托管任意静态服务均可运行。
重新生成：`python3 build_html.py`（从 `data/` 注入数据重建 `index.html`）；算法校验：`python3 simulate.py`。
